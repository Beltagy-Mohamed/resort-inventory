# محضر تنفيذ خطة الاختبار

المصدر: `خطة_اختبار_نظام_Resort_Inventory.xlsx`  
تاريخ التنفيذ: 2026-09-13

## النطاق المنفذ

قرئت الخطة كاملة: 1,554 حالة اختبار، منها 504 حالات High. نُفذت الفحوصات القابلة للتحقق محلياً على الشفرة وقاعدة اختبار Django. لم تُسجّل نتائج «نجاح» لحالات تحتاج متصفحاً حقيقياً أو جهاز موبايل أو بيئة Vercel أو بيانات إنتاج، حتى لا تكون النتيجة مضللة.

## إجراءات مُنفذة

| بند High من الخطة | الإجراء المنفذ | النتيجة |
|---|---|---|
| منع فقد السجل عند حذف منتج له حركات | تغيّر ارتباط الحركة بالمنتج إلى `PROTECT`، وتعرض الواجهة رسالة عربية بدلاً من الحذف | مُعالج؛ يحتاج تطبيق migration 0024 عند النشر |
| التزامن في IN/OUT | قفل سجل المنتج وسجل رصيده داخل transaction قبل قراءة وتعديل الكمية | مُعالج في الشفرة؛ يلزم اختبار حمل PostgreSQL قبل الإنتاج |
| منع تغيير الرصيد عبر تعديل المنتج | حقل الكمية معطّل في نموذج التعديل، والتحديث يتم عبر حركة استلام/صرف/جرد | مُعالج |
| النصوص الفارغة أو المضللة | Trim للنصوص ورفض Null byte ومحارف Unicode لاتجاه النص المخفية | مُعالج |
| صلاحية عرض المنتجات | قائمة المنتجات والتفاصيل ومنخفض المخزون تتطلب `inventory.view_product` من الخادم | مُعالج |
| أداء سجل النشاط | `select_related` للمستخدم والمنتج لتجنب استعلام إضافي لكل صف | مُعالج |
| اتساق migrations | أضيف migration 0024 وتحقق الفحص من عدم وجود تغييرات معلقة | ناجح |

## فحوصات منفذة ونتيجتها

| الأمر | النتيجة |
|---|---|
| `python manage.py check` | ناجح بلا أخطاء |
| `python manage.py makemigrations --check --dry-run` | ناجح: `No changes detected` |
| `python manage.py test` | ناجح: 5 اختبارات |

التحذير غير الحاجب الوحيد أثناء الاختبارات هو عدم وجود مجلد `staticfiles/` محلياً؛ ينشأ في بيئة النشر عبر `collectstatic --noinput`.

## حالات لا يمكن إعلانها «منفذة» محلياً

- 12 حالة High خاصة بطباعة QR/Barcode/Label أصبحت غير منطبقة، لأن هذه الميزات حُذفت من النسخة الحالية.
- اختبار الأداء مع 10,000+ منتج، التزامن الحقيقي، النسخ الاحتياطي والاسترجاع، والأمن على بيئة HTTPS يحتاج PostgreSQL وstaging.
- اختبارات التصميم والموبايل وChrome/Firefox/Edge وقارئ الشاشة تحتاج متصفحات وأجهزة فعلية.
- اختبار Vercel لا يُنفذ لأن البنية الحالية لا تتضمن نشر Vercel، ولا يُوصى باستخدامه لهذا التطبيق stateful.

## الخطوة التالية قبل النشر

نفّذ `python manage.py migrate` أولاً في بيئة staging بعد backup لتطبيق migration 0024، ثم اختبر IN/OUT/ADJUST بمستخدم Staff وAdmin على PostgreSQL. لا تطبق migration على قاعدة إنتاج قبل نسخة احتياطية قابلة للاسترجاع.
