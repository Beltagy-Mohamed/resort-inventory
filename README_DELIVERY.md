# Ordinance System

نظام Django لOrdinance والأصناف والحركات والتقارير والصلاحيات.

## النسخة الحالية

- تحتوي على خدمة المخزون `inventory/services/inventory_service.py` وتعمل على
  تنفيذ حركات الإضافة والصرف والتحويل داخل معاملات قاعدة بيانات آمنة.
- ميزة QR والباركود غير موجودة في النسخة التشغيلية الحالية ولا يعتمد عليها
  أي مسار أو نموذج أو صفحة.
- أصناف القائد معزولة عن جميع القوائم والتقارير وسجل النشاط العام، ولا تظهر
  إلا للمستخدم المعين صراحةً في إعداد صلاحية القائد.

## التشغيل والنشر

ابدأ من [OFFLINE_GOVERNMENT_DEPLOYMENT_AR.md](OFFLINE_GOVERNMENT_DEPLOYMENT_AR.md)
للتشغيل داخل مؤسسة بلا إنترنت، ومن `DEPLOYMENT.md` للنشر المعتاد.

لا تُضمّن ملف `.env` الحقيقي أو نسخة إنتاج من قاعدة البيانات في أي أرشيف تسليم.
